# 📦 Inventário de Caixas

Esta é uma aplicação web desenvolvida em Python com **Streamlit** para gerir e organizar o inventário de caixas de forma simples e intuitiva. 

A aplicação lê e atualiza os dados diretamente a partir de um ficheiro Excel local incluído no repositório.

## 🚀 Funcionalidades
* **Visualização do Inventário:** Consulta rápida do estado atual das caixas.
* **Leitura Direta:** Integração automática com a base de dados em Excel.
* **Interface Simples:** Desenvolvida para ser intuitiva e fácil de usar no dia a dia.
